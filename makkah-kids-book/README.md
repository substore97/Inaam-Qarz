# مكة المكرمة والمدينة المنورة

Arabic kids picture book (Makkah and Madinah, reading-only, kx combo 72) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Makkah-Kids "مكة المكرمة والمدينة المنورة"`

Outputs: `Makkah-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
