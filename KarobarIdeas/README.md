# کاروباری آئیڈیاز (Android App)

مکمل اردو زبان میں کاروباری آئیڈیاز کی ایپ۔

## خصوصیات
- 36 کاروباری آئیڈیاز، 6 زمروں میں (کھانا پینا، آن لائن، گھر سے کاروبار، زراعت و مویشی، خدمات، دکان و تجارت)
- ہر آئیڈیا میں: تفصیل، سرمایہ، متوقع آمدنی، مشکل کا درجہ، شروع کرنے کا طریقہ اور مشورے
- تلاش، زمرہ فلٹر، "آج کا آئیڈیا"
- پسندیدہ آئیڈیاز محفوظ کریں (♥)
- واٹس ایپ وغیرہ پر شیئر کریں
- نستعلیق فونٹ (Noto Nastaliq Urdu) اور دائیں سے بائیں (RTL) ڈیزائن
- انٹرنیٹ کی ضرورت نہیں

## APK
