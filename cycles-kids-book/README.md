# من بيضة إلى فراشة

Arabic kids picture book (From an Egg to a Butterfly, reading-only, kx combo 7) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Cycles-Kids "من بيضة إلى فراشة"`

Outputs: `Cycles-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
