# الأسرع والأبطأ

Arabic kids picture book (The Fastest and the Slowest, reading-only, kx combo 17) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Fastslow-Kids "الأسرع والأبطأ"`

Outputs: `Fastslow-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
