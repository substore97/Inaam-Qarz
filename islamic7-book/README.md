# دراساتي الإسلامية ٧

Arabic kids picture book (Islamic studies, seventh-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Islamiyyah-7 "دراساتي الإسلامية ٧"`

Outputs: `Islamiyyah-7-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
