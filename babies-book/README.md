# صِغَارُ الحَيَوَانَات — Baby Animals

A 24-page A4 Arabic book for kids aged 3–7: 12 animals and the classical Arabic names of their young, with 3D illustrations.

Rebuild: `cd babies-book && node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Sighar-Al-Hayawanat "صغار الحيوانات"`
