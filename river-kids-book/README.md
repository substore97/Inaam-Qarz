# النهر والبحيرة

Arabic kids picture book (The River and the Lake, reading-only, kx combo 8) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js River-Kids "النهر والبحيرة"`

Outputs: `River-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
