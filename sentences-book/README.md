# جملتي الأولى

Arabic kids picture book (first short sentences, grade 1, layout k6) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Jumlati-Al-Ula "جملتي الأولى"`

Outputs: `Jumlati-Al-Ula-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
