# تجارب علمية مدهشة

Arabic kids picture book (Amazing Science Experiments, reading-only, layout k32) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Tajarib-Ilmiyya "تجارب علمية مدهشة"`

Outputs: `Tajarib-Ilmiyya-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
