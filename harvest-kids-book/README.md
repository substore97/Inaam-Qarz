# المزارع والحصاد

Arabic kids picture book (The Farmer and the Harvest, reading-only, kx combo 93) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Harvest-Kids "المزارع والحصاد"`

Outputs: `Harvest-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
