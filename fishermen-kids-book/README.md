# الصياد والقارب

Arabic kids picture book (The Fisherman and the Boat, reading-only, kx combo 94) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Fishermen-Kids "الصياد والقارب"`

Outputs: `Fishermen-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
