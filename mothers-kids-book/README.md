# أمهات وصغار

Arabic kids picture book (Mothers and Babies, reading-only, kx combo 6) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Mothers-Kids "أمهات وصغار"`

Outputs: `Mothers-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
