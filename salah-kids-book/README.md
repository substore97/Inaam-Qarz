# صلاتي

Arabic kids picture book (My Prayer, reading-only, kx combo 62) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Salah-Kids "صلاتي"`

Outputs: `Salah-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
