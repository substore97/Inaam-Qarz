# صحرائي الجميلة

Arabic kids picture book (the desert, grade 1, layout k10) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Sahrai "صحرائي الجميلة"`

Outputs: `Sahrai-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
