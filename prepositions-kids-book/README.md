# في وعلى ومن

Arabic kids picture book (In, On and From, reading-only, kx combo 58) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Prepositions-Kids "في وعلى ومن"`

Outputs: `Prepositions-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
