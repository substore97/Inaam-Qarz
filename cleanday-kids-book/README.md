# يوم التنظيف

Arabic kids picture book (Cleaning Day, reading-only, kx combo 36) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Cleanday-Kids "يوم التنظيف"`

Outputs: `Cleanday-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
