# رياضياتي الجميلة ٤

Arabic kids picture book (math, fourth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-4 "رياضياتي الجميلة ٤"`

Outputs: `Riyadiyyati-4-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
