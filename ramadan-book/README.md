# رمضان والعيد

Arabic kids picture book (Ramadan & Eid, grade 1, layout k1) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ramadani "رمضان والعيد"`

Outputs: `Ramadani-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
