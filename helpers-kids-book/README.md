# أبطال يساعدوننا

Arabic kids picture book (Heroes Who Help Us, reading-only, kx combo 91) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Helpers-Kids "أبطال يساعدوننا"`

Outputs: `Helpers-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
