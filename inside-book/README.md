# جسمي من الداخل

Arabic kids picture book (organs of the body, grade 1 reading-only, layout k13) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Jismi-Min-Ad-Dakhil "جسمي من الداخل"`

Outputs: `Jismi-Min-Ad-Dakhil-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
