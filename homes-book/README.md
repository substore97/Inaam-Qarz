# بيوت الحيوانات

Arabic kids picture book (animal homes) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Buyut-Al-Hayawanat "بيوت الحيوانات"`

Outputs: `Buyut-Al-Hayawanat-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
