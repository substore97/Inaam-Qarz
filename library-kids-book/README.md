# في المكتبة

Arabic kids picture book (At the Library, reading-only, kx combo 30) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Library-Kids "في المكتبة"`

Outputs: `Library-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
