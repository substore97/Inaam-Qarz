# لغتي الجميلة ٣

Arabic kids picture book (Arabic language, third-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Lughati-3 "لغتي الجميلة ٣"`

Outputs: `Lughati-3-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
