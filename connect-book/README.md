# أتواصل مع الناس

Arabic kids picture book (communication & its manners, grade 1, layout k8) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Atawasal "أتواصل مع الناس"`

Outputs: `Atawasal-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
