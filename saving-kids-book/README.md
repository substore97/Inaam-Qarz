# أحافظ على الماء والكهرباء

Arabic kids picture book (I Save Water and Electricity, reading-only, kx combo 51) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Saving-Kids "أحافظ على الماء والكهرباء"`

Outputs: `Saving-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
