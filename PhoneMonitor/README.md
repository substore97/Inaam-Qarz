# Phone Monitor / فون مانیٹر

Android app (English + Urdu) that shows what is happening on the phone:
background apps, storage, battery, data usage and cache.

- Ready APK: `release/PhoneMonitor.apk` (Android 8.0+)
- Build: `ANDROID_HOME=<sdk> gradle assembleRelease`

On first launch grant **Usage access** when asked; without it Android only
exposes RAM, battery and the app list.
