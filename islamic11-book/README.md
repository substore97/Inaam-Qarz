# دراساتي الإسلامية ١١

Arabic kids picture book (Islamic studies, eleventh-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Islamiyyah-11 "دراساتي الإسلامية ١١"`

Outputs: `Islamiyyah-11-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
