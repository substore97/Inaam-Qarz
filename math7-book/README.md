# رياضياتي الجميلة ٧

Arabic kids picture book (math, seventh-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-7 "رياضياتي الجميلة ٧"`

Outputs: `Riyadiyyati-7-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
