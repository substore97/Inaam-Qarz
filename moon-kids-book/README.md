# القمر صديقي

Arabic kids picture book (The Moon, My Friend, reading-only, kx combo 11) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Moon-Kids "القمر صديقي"`

Outputs: `Moon-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
