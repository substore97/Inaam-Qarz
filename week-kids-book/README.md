# أيام الأسبوع

Arabic kids picture book (Days of the Week, reading-only, kx combo 46) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Week-Kids "أيام الأسبوع"`

Outputs: `Week-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
