# موسوعة الفواكه والخضار

Arabic kids picture book (My Fruit & Vegetable Encyclopedia, reading-only, layout k34) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Mawsuat-Al-Fawakih "موسوعة الفواكه والخضار"`

Outputs: `Mawsuat-Al-Fawakih-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
