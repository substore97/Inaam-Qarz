# My English Book 4

Arabic kids picture book (English, fourth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js My-English-Book-4 "My English Book 4"`

Outputs: `My-English-Book-4-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
