# آداب الطعام

Arabic kids picture book (Table Manners, reading-only, kx combo 67) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Tablemanners-Kids "آداب الطعام"`

Outputs: `Tablemanners-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
