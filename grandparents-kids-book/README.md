# زيارة جدي وجدتي

Arabic kids picture book (Visiting Grandpa and Grandma, reading-only, kx combo 32) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Grandparents-Kids "زيارة جدي وجدتي"`

Outputs: `Grandparents-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
