# أدعية يومي

Arabic kids picture book (My Daily Duas, reading-only, kx combo 66) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Dailyduas-Kids "أدعية يومي"`

Outputs: `Dailyduas-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
