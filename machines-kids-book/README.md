# آلات البناء

Arabic kids picture book (Building Machines, reading-only, kx combo 92) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Machines-Kids "آلات البناء"`

Outputs: `Machines-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
