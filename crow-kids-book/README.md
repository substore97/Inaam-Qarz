# الغراب الذكي

Arabic kids picture book (The Clever Crow, reading-only, kx combo 90) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Crow-Kids "الغراب الذكي"`

Outputs: `Crow-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
