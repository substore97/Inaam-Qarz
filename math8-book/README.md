# رياضياتي الجميلة ٨

Arabic kids picture book (math, eighth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-8 "رياضياتي الجميلة ٨"`

Outputs: `Riyadiyyati-8-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
