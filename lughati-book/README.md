# لغتي الجميلة

Arabic kids picture book (Arabic language, first-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Lughati-Al-Jameela "لغتي الجميلة"`

Outputs: `Lughati-Al-Jameela-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
