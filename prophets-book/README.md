# أنبياء الله

Arabic kids picture book (12 prophets of Allah, grade 1, layout k3) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Anbiyau-Allah "أنبياء الله"`

Outputs: `Anbiyau-Allah-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
