# دراساتي الإسلامية

Arabic kids picture book (Islamic studies, first-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Dirasati-Al-Islamiyya "دراساتي الإسلامية"`

Outputs: `Dirasati-Al-Islamiyya-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
