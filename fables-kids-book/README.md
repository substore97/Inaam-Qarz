# حكايات الحكماء من الحيوانات

Arabic kids picture book (Wise Animal Fables, reading-only, kx combo 89) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Fables-Kids "حكايات الحكماء من الحيوانات"`

Outputs: `Fables-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
