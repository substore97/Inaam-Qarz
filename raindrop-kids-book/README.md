# رحلة قطرة المطر

Arabic kids picture book (The Raindrop's Journey, reading-only, kx combo 14) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Raindrop-Kids "رحلة قطرة المطر"`

Outputs: `Raindrop-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
