# حكايات الجمع والطرح

Arabic kids picture book (Adding and Taking Away Stories, reading-only, kx combo 60) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Addstories-Kids "حكايات الجمع والطرح"`

Outputs: `Addstories-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
