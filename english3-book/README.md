# My English Book 3

Arabic kids picture book (English, third-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js My-English-Book-3 "My English Book 3"`

Outputs: `My-English-Book-3-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
