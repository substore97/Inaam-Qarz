# حيوانات البلاد الباردة

Arabic kids picture book (Animals of the Cold Lands, reading-only, kx combo 2) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Cold-Kids "حيوانات البلاد الباردة"`

Outputs: `Cold-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
