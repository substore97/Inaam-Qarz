# الأرض بيتنا

Arabic kids picture book (The Earth, Our Home, reading-only, kx combo 96) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Earth-Kids "الأرض بيتنا"`

Outputs: `Earth-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
