# طيور ملونة

Arabic kids picture book (Colourful Birds, reading-only, kx combo 4) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Birds-Kids "طيور ملونة"`

Outputs: `Birds-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
