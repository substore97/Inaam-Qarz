# أشكر الله

Arabic kids picture book (I Thank Allah, reading-only, kx combo 75) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Shukr-Kids "أشكر الله"`

Outputs: `Shukr-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
