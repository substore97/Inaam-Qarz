# في سوق الخضار

Arabic kids picture book (At the Vegetable Market, reading-only, kx combo 40) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Market-Kids "في سوق الخضار"`

Outputs: `Market-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
