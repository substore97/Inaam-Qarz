# Brief: first-grade Arabic READING book (Baghdadi-qaida style), content JSON

Children aged 6–7 (first grade, Arab countries) learn to read with harakat. The book goes step by step:
fatha → kasra → damma → all three → sentences → short passages. Letter tables are generated by code; YOU write the
words, phrases, sentences and passages. The owner demands **100% correct Arabic with correct, complete harakat**.
Reading only — no writing tasks, no "اكتب", no blanks.

Write ONE file (name given in your task) with exactly this shape:
```json
{
 "fatha_words":   ["كَتَبَ", "..."],          // 15 real words of 3 letters, EVERY letter with fatha only (no sukun/shadda/madd/tanween/alif)
 "fatha_phrases": ["دَرَسَ وَكَتَبَ", "..."],  // 9 pairs "X وَY", every letter fatha only
 "kasra_words":   ["شَرِبَ", "..."],           // 16 real 3-letter words using ONLY fatha and kasra (each word has at least one kasra)
 "kasra_phrases": ["..."],                    // 6 pairs "X وَY" using only fatha and kasra
 "damma_words":   ["كَبُرَ", "..."],           // 15 real 3-letter words using ONLY fatha and damma (each has at least one damma)
 "three_words":   ["كُتِبَ", "..."],           // 40 real 3-letter words using fatha/kasra/damma only (no sukun, shadda, madd, tanween)
 "three_phrases": ["..."],                    // 12 pairs "X وَY" with the same rule
 "cards":   ["ذَهَبَ سَامِرٌ إِلَى السُّوقِ.", "..."],   // 16 short complete sentences (3–6 words), FULL tashkeel, child life, end with «.»
 "stories": [ {"art": "cat", "lines": ["أُحِبُّ قِطَّتِي كَثِيرًا.", "..."]} ]  // 8 passages, 4–6 short lines each, FULL tashkeel, art from the list
}
```
Rules:
- Every word must be a real, common Fusha word a child can understand (verbs in past tense are fine: كَتَبَ، فَتَحَ،
  جَلَسَ؛ passive past like كُتِبَ is allowed in three_words). No rare or obscene/negative words.
- Full, correct tashkeel on EVERY letter in cards and stories (except long-vowel letters ا و ي used as madd, and «ال»
  of the definite article which takes no harakah on alif; shadda + haraka where needed; tanween where grammatical).
- Correct hamza spelling, ة/ه, ى/ي. Arabic punctuation (، .).
- Content: family, school, home, animals, nature, good manners, Islam (respectful, simple: الصلاة، الصدق، بر الوالدين).
  Use Arab children's names (سَامِرٌ، لَيْلَى، خَالِدٌ، مَرْيَمُ …).
- No repeated words inside the file.
- Allowed art names for stories (choose the one that fits): cat, dog, family, house, school, teacher, students, mosque,
  park, tree, sun, moon, sparrow, nest, train, car, bus, market, bakery, apple, banana, watermelon, fish, sailboat,
  kite, beachball, bigbook, rabbit, duck, chicken, cow, sheep, horse, camel_, desert, rainbow, raincloud, flower,
  e_flowers, grandpa, grandma, mother, father, brother, sister, baby, doctor, farmer, v_read, v_eat, v_pray, v_play,
  h_hands, h_teeth, m_help, m_share, m_thanks, m_parents, m_animals, bicycle, plane, umbrella, football, library,
  bee, butterfly, owl, whale, dolphin, garden: use e_park.

Check with `node check.js <your file>` until it prints OK, then proofread every word yourself once.
Reply only with the file name and anything you were unsure about.
