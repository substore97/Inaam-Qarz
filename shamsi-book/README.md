# الحروف الشمسية والقمرية

Arabic kids picture book (sun & moon letters) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Al-Huruf-Ash-Shamsiyya "الحروف الشمسية والقمرية"`

Outputs: `Al-Huruf-Ash-Shamsiyya-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
