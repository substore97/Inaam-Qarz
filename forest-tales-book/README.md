# حكايات الغابة

Arabic kids picture book (Forest Tales, reading-only, layout k22) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Hikayat-Al-Ghaba "حكايات الغابة"`

Outputs: `Hikayat-Al-Ghaba-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
