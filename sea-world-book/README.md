# عالم البحار

Arabic kids picture book (The World of the Seas, reading-only, layout k19) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Alam-Al-Bihar "عالم البحار"`

Outputs: `Alam-Al-Bihar-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
