# الغيمة الصغيرة

Arabic kids picture book (The Little Cloud, reading-only, kx combo 84) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Cloud-Kids "الغيمة الصغيرة"`

Outputs: `Cloud-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
