# حيواني الأليف

Arabic kids picture book (My Pet, reading-only, kx combo 5) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Pets-Kids "حيواني الأليف"`

Outputs: `Pets-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
