# أقارن وأقيس

Arabic kids picture book (comparing & measuring) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Uqarinu-wa-Aqisu "أقارن وأقيس"`

Outputs: `Uqarinu-wa-Aqisu-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
