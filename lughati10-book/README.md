# لغتي الجميلة ١٠

Arabic kids picture book (Arabic language, tenth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Lughati-10 "لغتي الجميلة ١٠"`

Outputs: `Lughati-10-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
