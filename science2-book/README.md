# علومي الجميلة ٢

Arabic kids picture book (science, second-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ulumi-2 "علومي الجميلة ٢"`

Outputs: `Ulumi-2-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
