# في الحديقة العامة

Arabic kids picture book (In the Park, reading-only, kx combo 27) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Park-Kids "في الحديقة العامة"`

Outputs: `Park-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
