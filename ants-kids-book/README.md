# النملة المجتهدة

Arabic kids picture book (The Hard-Working Ant, reading-only, kx combo 82) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ants-Kids "النملة المجتهدة"`

Outputs: `Ants-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
