# رياضياتي الجميلة ٦

Arabic kids picture book (math, sixth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-6 "رياضياتي الجميلة ٦"`

Outputs: `Riyadiyyati-6-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
