# ألعابي المفضلة

Arabic kids picture book (My Favourite Toys, reading-only, kx combo 37) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Toys-Kids "ألعابي المفضلة"`

Outputs: `Toys-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
