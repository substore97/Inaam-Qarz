# عجائب الطبيعة

Arabic kids picture book (Wonders of Nature, reading-only, layout k21) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ajaib-At-Tabia "عجائب الطبيعة"`

Outputs: `Ajaib-At-Tabia-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
