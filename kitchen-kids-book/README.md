# في المطبخ

Arabic kids picture book (In the Kitchen, reading-only, kx combo 23) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Kitchen-Kids "في المطبخ"`

Outputs: `Kitchen-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
