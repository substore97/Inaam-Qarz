# أشجاري الجميلة

Arabic kids picture book (My Beautiful Trees, reading-only, kx combo 9) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Trees-Kids "أشجاري الجميلة"`

Outputs: `Trees-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
