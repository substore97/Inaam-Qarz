# كلماتي الأولى

Arabic kids picture book (My First Words, reading-only, kx combo 53) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Firstwords-Kids "كلماتي الأولى"`

Outputs: `Firstwords-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
