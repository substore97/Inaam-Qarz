# ألوان من حولي

Arabic kids picture book (Colours Around Me, reading-only, kx combo 41) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Colors-Kids "ألوان من حولي"`

Outputs: `Colors-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
