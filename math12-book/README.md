# رياضياتي الجميلة ١٢

Arabic kids picture book (math, twelfth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-12 "رياضياتي الجميلة ١٢"`

Outputs: `Riyadiyyati-12-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
