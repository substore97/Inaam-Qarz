# أحافظ على بيئتي

Arabic kids picture book (caring for the environment) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Uhafizu-Ala-Biati "أحافظ على بيئتي"`

Outputs: `Uhafizu-Ala-Biati-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
