# My English Book 9

Arabic kids picture book (English, ninth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js My-English-Book-9 "My English Book 9"`

Outputs: `My-English-Book-9-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
