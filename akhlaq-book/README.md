# أخلاق المسلم الصغير

Arabic kids picture book (Good Manners of a Little Muslim, reading-only, layout k27) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Akhlaq-Al-Muslim "أخلاق المسلم الصغير"`

Outputs: `Akhlaq-Al-Muslim-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
