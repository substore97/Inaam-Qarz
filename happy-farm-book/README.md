# المزرعة السعيدة

Arabic kids picture book (The Happy Farm, reading-only, layout k25) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Al-Mazraa-As-Saida "المزرعة السعيدة"`

Outputs: `Al-Mazraa-As-Saida-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
