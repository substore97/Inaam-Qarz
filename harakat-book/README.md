# حَرَكَاتِي الجَمِيلَة — My Arabic Vowel Marks

A 20-page A4 book for kids aged 4–7: fatha, kasra, damma, sukun, shadda, tanween, long vowels and a syllable chart.

Rebuild: `cd harakat-book && node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Harakati-Al-Jameela "حركاتي الجميلة"`
