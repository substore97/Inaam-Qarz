# الجمل الصغير

Arabic kids picture book (The Little Camel, reading-only, kx combo 86) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Littlecamel-Kids "الجمل الصغير"`

Outputs: `Littlecamel-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
