# نزهة جميلة

Arabic kids picture book (A Lovely Picnic, reading-only, kx combo 34) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Picnic-Kids "نزهة جميلة"`

Outputs: `Picnic-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
