# حديقة الحيوانات

Arabic kids picture book (At the Zoo, reading-only, kx combo 29) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Zoo-Kids "حديقة الحيوانات"`

Outputs: `Zoo-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
