# لغتي الجميلة ١١

Arabic kids picture book (Arabic language, eleventh-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Lughati-11 "لغتي الجميلة ١١"`

Outputs: `Lughati-11-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
