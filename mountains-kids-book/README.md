# الجبال والصخور

Arabic kids picture book (Mountains and Rocks, reading-only, kx combo 15) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Mountains-Kids "الجبال والصخور"`

Outputs: `Mountains-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
