# يوم الجمعة

Arabic kids picture book (Friday, reading-only, kx combo 69) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Friday-Kids "يوم الجمعة"`

Outputs: `Friday-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
