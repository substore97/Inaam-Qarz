# رحلة بالقطار

Arabic kids picture book (A Train Journey, reading-only, kx combo 87) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Train-Kids "رحلة بالقطار"`

Outputs: `Train-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
