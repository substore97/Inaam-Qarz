# مَدِينَتِي الجَمِيلَة (My Beautiful City)

Arabic kids' picture book about places in the city, in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Madinati-Al-Jameela "مدينتي الجميلة"`

Outputs: `Madinati-Al-Jameela-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
