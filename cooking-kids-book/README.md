# أطبخ مع أمي

Arabic kids picture book (Cooking with Mum, reading-only, kx combo 35) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Cooking-Kids "أطبخ مع أمي"`

Outputs: `Cooking-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
