# دراساتي الإسلامية ٣

Arabic kids picture book (Islamic studies, third-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Dirasati-Al-Islamiyya-3 "دراساتي الإسلامية ٣"`

Outputs: `Dirasati-Al-Islamiyya-3-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
