# My English Book 5

Arabic kids picture book (English, fifth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js My-English-Book-5 "My English Book 5"`

Outputs: `My-English-Book-5-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
