# عالم الحشرات الصغيرة

Arabic kids picture book (The Little World of Insects, reading-only, kx combo 3) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Bugs-Kids "عالم الحشرات الصغيرة"`

Outputs: `Bugs-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
