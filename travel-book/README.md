# رحلتي الجميلة

Arabic kids picture book (travel & its manners, grade 1 reading-only, layout k15) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Rihlati "رحلتي الجميلة"`

Outputs: `Rihlati-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
