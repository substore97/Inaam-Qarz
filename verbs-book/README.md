# أفعالي الجميلة

Arabic kids picture book (action verbs) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Afali-Al-Jameela "أفعالي الجميلة"`

Outputs: `Afali-Al-Jameela-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
