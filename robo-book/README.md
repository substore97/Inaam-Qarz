# مغامرات روبو

Arabic kids picture book (Robo's Adventures, reading-only, layout k24) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Mughamarat-Robo "مغامرات روبو"`

Outputs: `Mughamarat-Robo-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
