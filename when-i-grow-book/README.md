# عندما أكبر

Arabic kids picture book (When I Grow Up, reading-only, layout k37) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Indama-Akbar "عندما أكبر"`

Outputs: `Indama-Akbar-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
