# واحد وكثير

Arabic kids picture book (singular & plural, grade 1, layout k5) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Wahid-wa-Kathir "واحد وكثير"`

Outputs: `Wahid-wa-Kathir-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
