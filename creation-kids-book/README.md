# من عجائب خلق الله

Arabic kids picture book (Wonders of Allah's Creation, reading-only, kx combo 78) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Creation-Kids "من عجائب خلق الله"`

Outputs: `Creation-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
