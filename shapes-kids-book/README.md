# أشكال من حولي

Arabic kids picture book (Shapes Around Me, reading-only, kx combo 42) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Shapes-Kids "أشكال من حولي"`

Outputs: `Shapes-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
