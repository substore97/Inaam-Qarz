# کلاڈ اے آئی — مکمل رہنما (Urdu guide to Claude AI)

85-page A4 Urdu guide (Noto Nastaliq Urdu), built on the Guldasta tooling: `python3 src/build.py && node src/pdf.js`
→ `Claude-Urdu-APP.pdf` (vector, ~2.8 MB). Content `content/w01..w03.json` + `content/static.json` (title, sections),
brief/validator in `tools/`. Inner pages white with black text, colourful cover (dark→terracotta, chat-bubble art,
no Anthropic logo), page number + «تالیف: انعام الرحمن» on every inner page, trademark/independence note on page 2.
