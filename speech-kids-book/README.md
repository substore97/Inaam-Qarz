# آداب الكلام والسلام

Arabic kids picture book (Manners of Speech and Salam, reading-only, kx combo 77) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Speech-Kids "آداب الكلام والسلام"`

Outputs: `Speech-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
