# لغتي الجميلة ٥

Arabic kids picture book (Arabic language, fifth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Lughati-5 "لغتي الجميلة ٥"`

Outputs: `Lughati-5-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
