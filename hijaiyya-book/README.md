# الحروف الهجائية

Arabic kids picture book (colourful Arabic alphabet, reading-only, layout k16) in 3D style, 36 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Al-Huruf-Al-Hijaiyya "الحروف الهجائية"`

Outputs: `Al-Huruf-Al-Hijaiyya-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
