# ألوان الحيوانات

Arabic kids picture book (Colours of Animals, reading-only, kx combo 19) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Animalcolors-Kids "ألوان الحيوانات"`

Outputs: `Animalcolors-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
