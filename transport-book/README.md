# وسائل النقل

Arabic kids picture book (Ways to Travel, reading-only, layout k35) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Wasail-An-Naql "وسائل النقل"`

Outputs: `Wasail-An-Naql-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
