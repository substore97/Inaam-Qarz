# لغتي الجميلة ٧

Arabic kids picture book (Arabic language, seventh-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Lughati-7 "لغتي الجميلة ٧"`

Outputs: `Lughati-7-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
