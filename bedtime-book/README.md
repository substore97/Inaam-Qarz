# حكايات قبل النوم

Arabic kids picture book (Bedtime Stories, reading-only, layout k23) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Hikayat-Qabl-An-Nawm "حكايات قبل النوم"`

Outputs: `Hikayat-Qabl-An-Nawm-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
