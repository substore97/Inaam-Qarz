# اختراعات مفيدة

Arabic kids picture book (Useful Inventions, reading-only, kx combo 95) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Inventions-Kids "اختراعات مفيدة"`

Outputs: `Inventions-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
