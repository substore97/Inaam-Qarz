# السمكة الصغيرة الشجاعة

Arabic kids picture book (The Brave Little Fish, reading-only, kx combo 81) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Bravefish-Kids "السمكة الصغيرة الشجاعة"`

Outputs: `Bravefish-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
