# في المطار

Arabic kids picture book (At the Airport, reading-only, kx combo 31) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Airport-Kids "في المطار"`

Outputs: `Airport-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
