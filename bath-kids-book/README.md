# وقت الاستحمام

Arabic kids picture book (Bath Time, reading-only, kx combo 24) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Bath-Kids "وقت الاستحمام"`

Outputs: `Bath-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
