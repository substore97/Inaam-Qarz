# رياضياتي الجميلة ٥

Arabic kids picture book (math, fifth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-5 "رياضياتي الجميلة ٥"`

Outputs: `Riyadiyyati-5-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
