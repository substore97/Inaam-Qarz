# رحلة الحج

Arabic kids picture book (The Journey of Hajj, reading-only, kx combo 71) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Hajj-Kids "رحلة الحج"`

Outputs: `Hajj-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
