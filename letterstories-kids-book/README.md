# حكايات الحروف

Arabic kids picture book (Stories of the Letters, reading-only, kx combo 98) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Letterstories-Kids "حكايات الحروف"`

Outputs: `Letterstories-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
