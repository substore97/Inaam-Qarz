# النظافة من الإيمان

Arabic kids picture book (Cleanliness Is Part of Faith, reading-only, kx combo 80) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Cleanfaith-Kids "النظافة من الإيمان"`

Outputs: `Cleanfaith-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
