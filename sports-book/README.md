# رياضتي الجميلة

Arabic kids picture book (sports) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadati-Al-Jameela "رياضتي الجميلة"`

Outputs: `Riyadati-Al-Jameela-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
