# الأكبر والأصغر

Arabic kids picture book (The Biggest and the Smallest, reading-only, kx combo 18) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Bigsmall-Kids "الأكبر والأصغر"`

Outputs: `Bigsmall-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
