# أركان الإسلام

Arabic kids picture book (The Pillars of Islam, reading-only, kx combo 63) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Islampillars-Kids "أركان الإسلام"`

Outputs: `Islampillars-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
