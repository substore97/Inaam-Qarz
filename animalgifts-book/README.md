# هدايا الحيوانات

Arabic kids picture book (what animals give us, grade 1, layout k4) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Hadaya-Al-Hayawanat "هدايا الحيوانات"`

Outputs: `Hadaya-Al-Hayawanat-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
