# أصحاب النبي

Arabic kids picture book (12 Companions, grade 1 reading-only, layout k14) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ashab-An-Nabi "أصحاب النبي"`

Outputs: `Ashab-An-Nabi-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
