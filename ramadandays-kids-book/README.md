# رمضان يوما بيوم

Arabic kids picture book (Ramadan Day by Day, reading-only, kx combo 70) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ramadandays-Kids "رمضان يوما بيوم"`

Outputs: `Ramadandays-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
