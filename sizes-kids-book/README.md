# طويل وقصير

Arabic kids picture book (Long and Short, reading-only, kx combo 44) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Sizes-Kids "طويل وقصير"`

Outputs: `Sizes-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
