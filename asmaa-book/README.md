# من أسماء الله الحسنى

Arabic kids picture book (Allah's Beautiful Names, reading-only, layout k28) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Asmaa-Allah-Al-Husna "من أسماء الله الحسنى"`

Outputs: `Asmaa-Allah-Al-Husna-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
