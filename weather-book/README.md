# الطقس والفصول

Arabic kids picture book (Weather & Seasons, reading-only, layout k36) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js At-Taqs-wal-Fusul "الطقس والفصول"`

Outputs: `At-Taqs-wal-Fusul-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
