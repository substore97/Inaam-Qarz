# حيوانات الأدغال

Arabic kids picture book (Jungle Animals, reading-only, kx combo 1) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Jungle-Kids "حيوانات الأدغال"`

Outputs: `Jungle-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
