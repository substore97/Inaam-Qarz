# أعدادي من ١ إلى ١٠٠

Arabic kids picture book (colourful numbers 1–100, reading-only, layout k17) in 3D style, 36 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Arqam-1-100 "أعدادي من ١ إلى ١٠٠"`

Outputs: `Arqam-1-100-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
