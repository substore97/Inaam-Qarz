# يوميات سارة

Arabic kids picture book (Sara's Diary, reading-only, layout k29) in 3D style, 50 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Yawmiyyat-Sara "يوميات سارة"`

Outputs: `Yawmiyyat-Sara-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
