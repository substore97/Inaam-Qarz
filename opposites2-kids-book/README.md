# الشيء وعكسه

Arabic kids picture book (Things and Their Opposites, reading-only, kx combo 59) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Opposites2-Kids "الشيء وعكسه"`

Outputs: `Opposites2-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
