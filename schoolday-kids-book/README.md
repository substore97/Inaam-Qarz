# يومي في المدرسة

Arabic kids picture book (My Day at School, reading-only, kx combo 33) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Schoolday-Kids "يومي في المدرسة"`

Outputs: `Schoolday-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
