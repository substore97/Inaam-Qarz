# أسأل وأجيب

Arabic kids picture book (question words with answers, grade 1 reading-only, layout k12) in 3D style, 24 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Asalu-wa-Ujib "أسأل وأجيب"`

Outputs: `Asalu-wa-Ujib-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
