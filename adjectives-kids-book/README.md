# صفات جميلة

Arabic kids picture book (Lovely Describing Words, reading-only, kx combo 57) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Adjectives-Kids "صفات جميلة"`

Outputs: `Adjectives-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
