# رياضياتي الجميلة ٢

Arabic kids picture book (math, second-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Riyadiyyati-2 "رياضياتي الجميلة ٢"`

Outputs: `Riyadiyyati-2-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
