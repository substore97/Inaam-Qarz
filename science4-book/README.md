# علومي الجميلة ٤

Arabic kids picture book (science, fourth-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ulumi-4 "علومي الجميلة ٤"`

Outputs: `Ulumi-4-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
