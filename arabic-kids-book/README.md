# حُرُوفِي الجَمِيلَة — My Beautiful Arabic Letters

A 36-page Arabic alphabet book for kids (ages 3–7) with 3D clay-style illustrations.

- `Huroofi-Al-Jameela-PRINT.pdf` — 8.5" × 8.5", 300 DPI (for printing)
- `Huroofi-Al-Jameela-MOBILE.pdf` — same book, smaller file for phones and apps

Rebuild: `node src/build.js && node src/pdf.js` (needs Node with Playwright and Python with Pillow).
Fonts (in `fonts/`) are SIL Open Font License, so they can be used commercially.
