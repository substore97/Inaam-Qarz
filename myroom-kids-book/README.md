# غرفتي المرتبة

Arabic kids picture book (My Tidy Room, reading-only, kx combo 22) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Myroom-Kids "غرفتي المرتبة"`

Outputs: `Myroom-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
