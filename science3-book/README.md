# علومي الجميلة ٣

Arabic kids picture book (science, third-grade syllabus) in 3D style, 48 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Ulumi-3 "علومي الجميلة ٣"`

Outputs: `Ulumi-3-APP.pdf` (Full HD), `-PRINT.pdf` (300 DPI), `-Cover.jpg`, `-PlayStore.txt`.
