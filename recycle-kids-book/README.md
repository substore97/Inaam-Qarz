# أعيد التدوير

Arabic kids picture book (I Recycle, reading-only, kx combo 52) in 3D style, 40 A4 pages.

Build: `node src/build.js && BOOK_DIR=$PWD node ../arabic-kids-book/src/pdf.js Recycle-Kids "أعيد التدوير"`

Outputs: `Recycle-Kids-APP.pdf` (Full HD, ≈4 MB) and `-PlayStore.txt` (set `PRINT=1` to also make the print PDF and cover).
